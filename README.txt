APNA RETRO TV — starter website
================================

Files:
- index.html : complete one-file website (HTML + CSS + JavaScript)

How to preview on Android:
1. Download and extract the ZIP.
2. Open index.html in a browser or a code editor with HTML preview.
3. For a public website, upload index.html to a static host such as GitHub Pages or Netlify.

Important:
- This is a functional visual starter with channel switching, power, mute toggle, and fullscreen.
- Channel entries are demo categories, not live TV streams yet.
- Add only official/publicly embeddable streams or videos you own/license. Do not scrape paid TV services or bypass DRM.
- The mute control is a UI toggle; it does not control audio until you connect a real video/audio source.
- Website name is a suggestion; check domain/trademark availability before using commercially.
